# 关于本文件夹内容

本文件夹内容均为旧版汉化补丁的提取内容，没有作任何二次修改，当然也无法确保一定完整。

并且对旧汉化的处理仅止步于提取文件以适配原始版本游戏，方便制作优化体验MOD。

对旧汉化文件的最低限度改动均出于尊重旧汉化组的各位前辈的劳动成果。

考虑到旧汉化距今已过去15年，并且亦不太适用于linux、手机转译等2025年开始流行的各种新的运行方式。

本文件夹仅作归档保留，一旦原汉化组成员对这份文件有异议，本项目维护者将尊重其意愿，对本项目内涉及旧汉化的内容做出处理。

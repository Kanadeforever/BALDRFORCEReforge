# BaldrForceGamepad v0.1-test7 配置说明

当前版本只开放一个用户配置参数：右摇杆鼠标灵敏度。

## 1. 配置文件

文件名：

```text
BaldrForceGamepad.ini
```

必须和 `BaldrForceGamepad.asi` 放在同一游戏目录。

## 2. Mouse.Sensitivity

默认：

```ini
[Mouse]
Sensitivity=1.00
```

含义：右摇杆控制游戏鼠标时的速度倍率。

示例：

```text
0.50 = 默认速度的一半
1.00 = 默认速度
1.50 = 默认速度的 1.5 倍
2.00 = 默认速度的两倍
```

插件内部把有效范围限制在 `0.10 ~ 5.00`，防止输入异常值后鼠标完全不可控制。

## 3. 固定输入规则，不提供开关

### 战斗

- D-Pad：原版 PC 语义，单按/按住步行，双击同方向并保持第二下跑步；
- 数字小键盘 8246：同上；
- 数字小键盘 7913：原版斜向；
- 左摇杆：直接跑；
- 键盘方向键：直接跑。

### 战斗外

- D-Pad 与左摇杆都进入游戏原版方向导航。

### 特殊按键

- START = 键盘 Esc；
- LT = 鼠标右键；
- RT = 鼠标左键；
- 右摇杆 = 鼠标。

LT/RT 不再同时作为普通游戏手柄按钮，START 也不再作为旧手柄第 10 按钮。

## 4. 已删除：光标自动隐藏

项目曾实验 `AutoHideSeconds`，但原版存在多种光标/VOICE 指示形态，实机不能可靠统一隐藏。

从 test5 起该功能已经删除，test7 继续保持删除状态。

旧 INI 如果残留：

```ini
AutoHideSeconds=...
```

也不会被读取。

## 5. 已删除：方向右打开剧情菜单

从 test7 起，插件不再提供任何：

- Right 打开右侧小快捷栏；
- Right 打开完整剧情菜单；
- Right 伪装 B；
- Right 伪造鼠标 hover/click。

Right 在所有场景都完全交还游戏原版。

因此 INI 也没有这项功能的开关。

# BaldrForceGamepad v0.1-test7 第三方依赖说明

## SDL3

BaldrForceGamepad 使用 SDL3 作为现代手柄输入前端。

当前项目记录并推荐：

```text
SDL 3.4.16
Windows x86 / 32-bit
发行包：SDL3-3.4.16-win32-x86.zip
记录的 ZIP SHA-256：beb4e86e4a101f66556162c3efff9fd1ad88f1761b63be35867a3336a72f8c41
```

游戏和 ASI 都是 32 位，因此必须使用 x86 SDL3.dll，不能使用 x64 或 ARM64。

## 放置方式

玩家：

```text
游戏目录\BaldrForceGamepad.asi
游戏目录\BaldrForceGamepad.ini
游戏目录\SDL3.dll
```

开发者也可以把核验过的 DLL 放到：

```text
source\third_party\SDL3\SDL3.dll
```

然后运行 `source\build.bat`，脚本会自动复制到 `release\`。

## 动态加载设计

ASI 不静态导入 SDL3。运行时通过：

```text
LoadLibraryA("SDL3.dll")
GetProcAddress(...)
```

取得实际使用的 SDL3 C ABI。

优点：

- 缺 DLL 时不会在 Windows DLL Loader 阶段直接让游戏报“缺失依赖”；
- SDL3 版本可以单独替换/回退；
- ASI 本体保持轻量；
- 更容易诊断加载失败。

## 缺少 SDL3.dll 时

现代手柄相关功能不会正常工作，包括：

- SDL3 D-Pad；
- 左/右摇杆；
- SDL3 按钮；
- START=Esc；
- LT/RT 鼠标键。

因此实机测试现代手柄前必须放入正确的 x86 SDL3.dll。

## 与 test7 功能删除无关

test7 删除的是剧情 Right 菜单功能和此前已经删除的光标自动隐藏功能；SDL3 仍是手柄输入核心依赖，没有删除。

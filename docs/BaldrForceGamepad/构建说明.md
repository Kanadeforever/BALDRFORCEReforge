# BaldrForceGamepad v0.1-test7 构建说明

## 1. 目标

本工程生成 BALDR FORCE 2003 PC 版专用的 32 位 ASI：`BaldrForceGamepad.asi`。

目标 EXE 必须是：

```text
BaldrForce.2003.exe
大小：987,136 bytes
SHA-256：5b65ecb1512b0cbf72cacdb5e981aa04f9c569698c6cab2f8877abf2d2cd42c5
```

## 2. 工具链

推荐：

- Clang/LLVM x86 Windows target；
- lld-link；
- 不需要 MSVC CRT；
- SDL3 不参与编译，只在游戏运行时动态加载。

`source\build.bat` 会先从 PATH 查找 `clang.exe` 与 `lld-link.exe`，找不到时再尝试 `C:\Program Files\LLVM\bin`。

## 3. 一键构建

进入 `source\` 后运行：

```bat
build.bat
```

脚本会：

1. 删除旧 `source\_build`；
2. 用 `-target i686-pc-windows-msvc -m32` 编译 `src\BaldrForceGamepad.c`；
3. 用 `lld-link /dll /machine:x86 /nodefaultlib` 生成 ASI；
4. 删除 `.lib/.exp/.pdb` 等非运行文件；
5. 把最新 INI 复制到 `release\`；
6. 如果 `source\third_party\SDL3\SDL3.dll` 存在，则一起复制到 `release\`。

## 4. 当前五个固定 Hook

```text
0x0040C700  键盘扫描码查询 / START=Esc
0x0040C710  鼠标 getter / LT/RT 最终按钮输出
0x0040C750  鼠标采集 / 右摇杆和 LT/RT 源状态
0x00411920  统一输入 / SDL3 按钮、方向与键盘方案
0x0041866A  跑步 Gate / 左摇杆和方向键直接跑
```

v0.1-test7 已删除 test1~test6 的剧情 Right 菜单功能，因此：

```text
0x00483CA0 不再 Hook
0x00486C60 不再 Hook
```

也不再编译 Message.ani 扫描、侧栏 action 8 自动化或 Right 按下沿状态机。

## 5. 机器码安全检查

初始化时先核对：

```text
0x40C700: 8B 4C 24 04 33 C0
0x40C710: 8B 44 24 04 85 C0
0x40C750: 83 EC 08 8D 44 24 00
0x411920: 51 53 55 56 57
0x41866A: A0 1C F2 7C 00
```

任何一处不匹配都会停止安装 Hook。

## 6. 编译后检查

正式产物应满足：

- PE32 / Intel i386；
- DLL；
- 导出 `InitializeASI`；
- 不依赖普通 C/C++ CRT；
- SDL3 不出现在静态 Import Directory；
- `-Wall -Wextra` 不应出现警告。

## 7. 包结构约束

根目录固定：

```text
docs\
source\
release\
```

源码直接放 `source\src\`，不要再多套一层工程目录。

每次改源码后必须同步遍历：

- `完整接档说明.md`
- `构建说明.md`
- `配置说明.md`
- `测试说明.md`
- `第三方依赖说明.md`
- `source\config\BaldrForceGamepad.ini`
- `release\BaldrForceGamepad.ini`
- 两份 SDL3 依赖说明文本

## 8. test7 与 test6 的构建差异

仅做收敛删除：

- 删除 `0x483CA0` Hook；
- 删除剧情 Right 自动化函数和状态；
- 删除剧情 Message.ani / 侧栏相关运行时地址；
- 目标机器码检查从六处缩为五处；
- START=Esc、LT/RT、移动与 SDL3 主结构不改。

所以 test7 的目的不是扩大改动面，而是减少 Hook 和状态污染风险。

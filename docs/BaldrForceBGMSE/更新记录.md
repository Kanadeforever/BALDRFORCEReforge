## v0.1-test1 + 目录重组（2026-09-25）

目录结构与构建系统调整，插件运行逻辑未变；文档合并为三篇。

- 源码按模块分目录：`source\BaldrForceBGMSE\` 下含 `build.bat`、`src`、`tools`、`data`、`templete`；
- 所有编译产物统一到**项目根** `release\`，不再放模块内部；新增项目根总脚本 `build_all.bat`（依次调用四个模块，`build_all.bat BGMSE` 可只编本模块）；
- 构建脚本改用本机 LLVM 工具链：clang 22.1.7 + lld-link（`C:\msys64\clang64\bin`），按 PATH → `C:\msys64\clang64\bin` → `C:\Program Files\LLVM\bin` 顺序自动探测，并把 clang 所在目录插到 PATH 最前；
- 因 MSYS2 clang64 不提供 `clang-cl.exe`，编译改用 `clang.exe --driver-mode=cl --target=i686-pc-windows-msvc`；
- 必须保留 `-fno-builtin-strlen`：clang 22 会把循环合成为 strlen 调用，`/nodefaultlib` 下没有 strlen 可链接，会报 `undefined symbol: _strlen`；
- 链接保留 `/nodefaultlib /timestamp:0`，产物确定性哈希保持稳定；构建后自动从 `release` 删除误生成的 `.lib`/`.exp`/`.pdb`；
- 新增 `templete\BaldrForceBGMSE.ini` 随包复制：构建脚本把 `templete\*` 复制到 `release\`，INI 不再手工维护第二份；
- 脚本自清 `build`、`__pycache__`、`*.pyc`；
- 本次构建实测产物：`BaldrForceBGMSE.asi` 12800 字节，SHA256 `866fb0d3d09d6d0389c55d943024cc83c098cbe21832e2ffbc9449b1e4823b74`；`BaldrForceBGMSE.ini` 287 字节，SHA256 `ca90ecaaaaac55bb976bedc0970bf454e5e54a9825348588e5442873dcf17663`；
- 静态验证实测：i386 / PE32 / DLL / 标准导入表为空 / 导出 `InitializeASI, _InitializeASI@0` / Entry RVA `0x00001B20`（旧文档记录的 `0x00001CA0`、13312 字节、`1fac4c77...` 均已作废）；
- 文档合并：原 7 篇（BGMInfo结构说明、使用与测试说明、完整接档说明、工具详细说明、当前版本说明、更新记录、构建说明）合并为 3 篇（完整接档说明、构建与发布、更新记录）。

## v0.1-test1（首个可编译测试版）

- 确认 BFE/BFSE `BGMInfo.DAT` 均为 30 × 0x44 + 9 字节相同表尾（2049 字节）；
- 确认 `+0x00..+0x3F` 是 PAC 内 WAV 资源名（CP932，NUL 结尾）；
- 确认 `+0x40` 是 1/100 秒 BGM 循环起点，`-1` 为非循环；BFSE 30 首中 28 首循环、`#29`/`#30` 非循环；
- 确认 BFE/BFSE 通过相同 BGM 编号索引 30 条表，编号可一一对应；
- 不修改剧情脚本，不修改 `Table.pac`，不重打包 `BGM.pac`；
- BGMInfo 内存只替换 BFSE 循环点，不覆盖 BFE/汉化版资源名字段（避免汉化曲名显示回归）；
- 两处原 BGM loader CALL（`0x00463892`、`0x004639B6`）改为运行时按编号传入 BFSE 文件名；
- 安装前校验三个 CALL 签名（`0x0046144C`、`0x00463892`、`0x004639B6`），不匹配则整体放弃，避免半补丁；
- 支持 `Source=Game`：读取游戏看到的 `BGM.pac`，兼容 Ultimate ASI Loader 的 update 虚拟覆盖；
- 支持 `Source=Local`：读取 ASI 同目录 `BFSE_BGM.pac`，保存 IAT 槽现值做链式调用，打开失败时回退原 `BGM.pac`；
- 增加中文诊断日志 `BaldrForceBGMSE.log`；
- 提供 BGMInfo 生成器 `generate_bgm_table.py`、中文对照 CSV、PE 构建验证器 `verify_build.py`；
- ASI 无 CRT、无标准导入表，从 PEB 解析 kernel32 导出；
- 当前等待实机测试。

# 构建说明

## 1. 包结构

```text
BaldrForceBGMSE_v0.1-test1\
├─ docs\
├─ release\
│  ├─ BaldrForceBGMSE.asi
│  └─ BaldrForceBGMSE.ini
└─ source\
   ├─ BaldrForceBGMSE.def
   ├─ build.bat
   ├─ src\
   │  ├─ BaldrForceBGMSE.cpp
   │  └─ BgmTable.generated.h
   ├─ tools\
   │  ├─ generate_bgm_table.py
   │  └─ verify_build.py
   └─ data\
      ├─ BFE_BGMInfo.DAT
      ├─ BFSE_BGMInfo.DAT
      └─ BGM信息对照.csv
```

## 2. 依赖

Windows 构建需要：

- Python 3；
- clang-cl；
- lld-link。

目标固定：

```text
i686-pc-windows-msvc
```

## 3. 一键构建

运行：

```bat
source\build.bat
```

流程：

1. 校验两份 BGMInfo.DAT 都是 2049 字节；
2. 校验 30×0x44 和相同 9 字节表尾；
3. 生成 `BgmTable.generated.h`；
4. 生成 `BGM信息对照.csv`；
5. clang-cl 编译 x86；
6. lld-link `/nodefaultlib /timestamp:0` 链接 ASI；
7. `verify_build.py` 验证 PE；
8. 清理中间目录。

`build.bat` 为 UTF-8 + CRLF，并执行：

```bat
chcp 65001 >nul
```

## 4. 为什么不用 Windows SDK 头文件/CRT

源码自己声明最小 Win32 类型，并从 PEB 里找到已加载的 `kernel32.dll`，再解析导出函数。

这样最终：

```text
Standard Import Directory = empty
```

需要的 API 包括：

- VirtualProtect；
- FlushInstructionCache；
- GetModuleFileNameA；
- GetPrivateProfileStringA；
- CreateFileA；
- WriteFile；
- CloseHandle。

如果 KERNEL32 导出转发到 KERNELBASE，源码会解析普通 `MODULE.Function` 转发字符串。

## 6. 重新构建后的最低检查

每次改源码后至少确认：

- `generate_bgm_table.py` 报告 30 条；
- BFSE 循环=28、非循环=2；
- 编译无错误；
- `verify_build.py` 全通过；
- `release` 只有 ASI 和 INI；
- 连续两次构建哈希一致；
- 所有文档同步最新地址、哈希和测试结论。

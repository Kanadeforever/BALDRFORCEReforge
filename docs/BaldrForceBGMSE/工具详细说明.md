# 工具详细说明

本包有两个自制 Python 工具。玩家运行游戏不需要 Python；只有开发/重建时使用。

## 1. `generate_bgm_table.py`

位置：

```text
source\tools\generate_bgm_table.py
```

### 输入

```text
source\data\BFE_BGMInfo.DAT
source\data\BFSE_BGMInfo.DAT
```

### 校验

工具会确认：

- 两份文件都恰好 2049 字节；
- 主体恰好 30×0x44；
- 表尾恰好是 `av\0av\0av\0`；
- 每条前 0x40 按 CP932 解析资源名；
- +0x40 按有符号 little-endian int32 读取循环点。

只要结构不符，就停止生成，避免不同版本数据静默混入插件。

### 输出

```text
source\src\BgmTable.generated.h
source\data\BGM信息对照.csv
```

头文件用十六进制字节数组保存 BFSE 30 条完整 0x44 数据，不依赖 C++ 源文件字符编码。

CSV 则提供给人阅读，列出两版 30 首的资源名、循环点原值和换算秒数。

## 2. `verify_build.py`

位置：

```text
source\tools\verify_build.py
```

直接解析生成的 PE，检查：

- MZ；
- PE 签名；
- i386；
- PE32；
- DLL 标志；
- 非零入口；
- 标准 Import Directory 为空；
- 导出 `InitializeASI`。

它只读 ASI，不修改文件。

## 3. 维护规则

如果以后 BFSE/BFE BGMInfo 数据发生变化：

1. 不要手工改 `BgmTable.generated.h`；
2. 更新 `source\data` 下两份 DAT；
3. 重新跑生成器；
4. 检查中文对照 CSV；
5. 重建 ASI；
6. 同步《BGMInfo结构说明.md》《当前版本说明.md》《完整接档说明.md》。

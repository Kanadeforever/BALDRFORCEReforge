# 工具详细说明

当前包保留 5 个自制 Python 工具。玩家正常运行 ASI 不需要 Python；这些工具用于离线映射、人工复核、回归检查、生成 C++ 静态表和验证最终 PE。

## 1. `generate_voice_table.py`

位置：

```text
source\tools\generate_voice_table.py
```

输入：

```text
source\data\BFE\
source\data\剧情语音映射_当前确定.json
```

把：

```text
BFE 脚本 + 逻辑文本记录号 -> BFSE VoiceTag
```

转换成运行时键：

```text
脚本真正执行流 FNV-1a32
+
0x000B 文本记录相对执行流的静态字节偏移
```

执行流边界：

```text
stream_start = 16 + (u32@0x08 * 4)
stream_size  = u32@0x0C
```

旧汉化 BFET 位于执行流之后，因此不会改变脚本身份。

安全检查包括：

- BFE 输入必须正好 301 个 BIN；
- 脚本执行流哈希不得碰撞；
- 映射脚本必须存在；
- 逻辑记录号必须有效；
- VoiceTag 必须能放入固定字段；
- 运行时 `(scriptHash, recordOffset)` 不得重复；
- 一个 BFE 记录对应多个 VoiceTag 时直接排除。

v0.1.1-test1 当前输出：

```text
245 个有安全映射的脚本
5891 条唯一 VoiceMap
4 条多 VoiceTag 冲突安全排除
```

它只生成：

```text
source\src\VoiceMap.generated.h
```

不会向 `release\` 生成运行时 CSV。

## 2. `verify_build.py`

位置：

```text
source\tools\verify_build.py
```

直接解析生成的 ASI，检查：

- `MZ` / `PE\0\0`；
- Machine = `0x014C`（i386）；
- PE32 OptionalHeader = `0x010B`；
- DLL 标志；
- 非零入口；
- Standard Import Directory 为空；
- 导出 `InitializeASI`；
- 导出 `_InitializeASI@0`。

只读文件，不修改 ASI。

## 3. `mapping\build_voice_map.py`

读取 BFE/BFSE NEXAS BIN，提取 0x000B 文本和 BFSE `@v`，结合：

- 正文相似度；
- 局部序列；
- 前后文；
- 剧情锚点；
- 人工正/负样本；

建立离线候选。模糊匹配只允许发生在离线阶段，正式 ASI 运行时不做模糊判断。

## 4. `mapping\build_review_sheet.py`

把低可信候选整理成适合人工查看的复核表，包括 BFSE/BFE 目标台词、上下文、候选位置、VoiceTag、相似度和人工备注栏。

本轮用户发现前后各 5 条对大幅分级改写不总是够用，因此另行产生了：

```text
source\data\前后20条定位复核.xlsx
```

该表保留 BFSE 与 BFE 目标前后各 20 条记录，用于人工检查“改写前后是否重新汇合”。

## 5. `mapping\verify_regression.py`

利用：

```text
人工确认通过.csv
人工确认不通过.csv
```

作为离线映射算法的回归门禁，防止调整算法后把已知错配重新自动接受，或丢失已确认正样本。

## 6. 本轮新增数据文件的角色

### `人工复核输入_20260920.xlsx`

用户本轮提供的原始人工确认工作簿副本，作为接档证据保留。

### `人工增补确认通过.csv`

从本轮工作簿中提取的 17 条新增人工通过项。它们相对 v0.1.0 是新的安全映射来源。

### `前后20条定位复核.xlsx`

对原“主线最后 45 条”中的 28 条尚未人工确认项进行 ±20 条上下文重新审计的可读工作簿；同时保留 17 条人工通过项，方便在同一张表理解完整 45 条状态。

### `前后20条定位通过.csv`

19 条通过长上下文唯一定位的新增项。

### `前后20条仍未定位.csv`

9 条即使扩大到 ±20 仍无法唯一确定的项目。它们**没有**进入当前 VoiceMap。

## 7. 当前完整映射数据流

```text
BFE/BFSE BIN
    ↓
build_voice_map.py
    ↓
候选 + 人工复核
    ↓
用户人工通过 17 条
    +
前后20条唯一定位 19 条
    ↓
剧情语音映射_当前确定.json
    ↓
generate_voice_table.py
    ↓
VoiceMap.generated.h
    ↓
BaldrForceVoiceSE.asi
```

以后如果继续补映射，不应手工编辑 `VoiceMap.generated.h`；应更新上游确认数据和 `剧情语音映射_当前确定.json`，再重新生成。

## 2. 构建依赖

需要：

- Python 3；
- `clang-cl`；
- `lld-link`。

目标：

```text
i686-pc-windows-msvc
```

ASI 使用 `/nodefaultlib`，不依赖 VC Runtime；链接使用 `/timestamp:0`，确保相同输入可重复构建。

## 3. 一键构建

Windows 下运行：

```bat
source\build.bat
```

步骤：

1. `generate_voice_table.py` 读取 301 个 BFE BIN 和 `剧情语音映射_当前确定.json`；
2. 重新生成 `src\VoiceMap.generated.h`；
3. 生成器验证哈希、记录边界、重复运行时键和多 VoiceTag 冲突；
4. `clang-cl` 编译 32 位目标；
5. `lld-link` 生成 `release\BaldrForceVoiceSE.asi`；
6. `verify_build.py` 验证 PE32/i386、DLL、入口、导出和空标准导入表；
7. 删除临时编译目录。

`build.bat` 保持 UTF-8 + CRLF，并执行：

```bat
chcp 65001 >nul
```

## 7. 发布/测试前复核

每次修改映射后至少确认：

1. 301 个 BFE BIN 完整；
2. VoiceMap 数量符合预期；
3. 4 条已知多 VoiceTag 冲突仍被排除；
4. `verify_build.py` 全部通过；
5. `release\` 只有 ASI；
6. ASI 中没有日志/覆盖率测试设施；
7. 修改过的映射要优先实机验证对应场景和 Backlog。

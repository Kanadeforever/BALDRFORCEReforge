## 2026-09-25 工程重组与构建迁移（当前工作树，未发布新版本号）

仓库目录重组到 `source` 下按模块分目录，本模块源码根变为 `source\BaldrForceVoiceSE`：

- 模块内固定为 `build.bat` / `src` / `tools` / `data`；本模块当前没有 `templete`（没有需要随 ASI 分发的文件）；
- 所有编译产物统一到项目根 `release`，不再放在模块内；本模块 `build.bat` 的输出路径改为 `..\..\release`；
- 新增项目根总编译脚本 `build_all.bat`，依次调用四个模块的 `build.bat`，带参数 `BGMSE / CN / GAMEPAD / VOICESE` 可只编一个。

构建脚本改用本机 LLVM 工具链：

- 工具链探测顺序改为 PATH -> `C:\msys64\clang64\bin` -> `C:\Program Files\LLVM\bin`，并把 clang 所在目录插到 PATH 最前（clang.exe 依赖同目录 DLL）；
- 明确改用 `clang.exe` 的 cl 驱动模式 `--driver-mode=cl`：MSYS2 的 clang64 不提供 `clang-cl.exe`；
- 新增 `-fno-builtin-strlen`：clang 22 会把循环合成为 `strlen` 调用，而 `/nodefaultlib` 下无 `strlen` 可链接，会报 `undefined symbol: _strlen`；
- 保留 `/timestamp:0` 确定性构建；构建后从 release 删除误生成的 `.lib` / `.exp` / `.pdb`；
- 工具链版本变化后，同一份源码的产物哈希与入口 RVA 随之变化：当前 `release\BaldrForceVoiceSE.asi` 为 122880 字节、SHA-256 `870327dd...c081d`、Entry RVA `0x00001290`；旧文档记录的 SHA-256 `30e6669e...`、Entry RVA `0x000012A0` 属重组前工具链的构建结果，不再当作当前值。

新增 templete 随包复制约定：每个模块的 `templete` 目录存放随 ASI 分发的文件（INI 等），构建时复制到 release。本模块没有随包文件，因此未新增该目录，`build.bat` 中也未加复制步骤；若将来需要，按同一约定补齐。

本轮运行时代码与映射数据均无变化：仍是 `v0.1.1-test1`（5891 条 VoiceMap / 245 个脚本 / 4 条冲突排除）。

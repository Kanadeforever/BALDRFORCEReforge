# 测试说明

> 当前测试版本：`BaldrForceCN Runtime v1.0.4-crashfix1`

## 1. 最小环境

优先只加载 `BaldrForceCN.asi`，排除其它插件变量。把 `BaldrForceCN.ini` 保持默认：`FontFace=`、`EnableLog=1`。

启动日志第一行应为：

```text
BaldrForceCN 中文运行时 ASI v1.0.4-crashfix1
```

并应看到 DAT overlay、全局 DBCS/GDI、低层 DBCS routing、glyph state、1bpp mask、opcode 0x0B Hook、增强 VEH 全部成功。

## 2. 必测 A：八木泽名片

走到“国连军治安维持局信息管理处第一小队队长 / 八木泽 宗次”名片。v1.0.3 会在其后稳定崩溃，真实 EIP 是 `0x0048A974`。

本版通过标准：能够继续剧情，不发生同点崩溃。若日志出现 Unicode fallback 命中属于正常且是高价值证据；请保留完整日志。

## 3. 必测 B：Backlog #64

走到 `jyosyo05.bin #64`：

```text
「………什么……」
```

通过标准：右侧结束符完整，不出现末尾方块；随后打开 Backlog 可以正常查看，不崩溃。日志应出现类似：

```text
[诊断][Backlog复现句] ... 脚本源count仍为21，运行时value object count已更新为27。
```

## 4. 回归测试

至少快速进入：Information/阅览信息、TORU 练习模式、HELLMODE Trial 菜单。它们此前分别在 test11/test12 已实机通过，本轮没有改变 DBCS routing、glyph-state、1bpp Hook 或资源白名单，画面应继续正常中文。

## 5. FontFace 测试（可选）

先完成默认字体测试，再在 INI 设置一个已安装字体，例如 `FontFace=Microsoft YaHei`。重新启动后中文字体应变化；如果字体缺少某字，本版应优先显示 fallback/空白，而不是崩溃。

## 6. 仍崩溃时

不要截取部分日志。退出后直接提供完整 `BaldrForceCN.log`，并说明是哪个画面/哪个操作触发。增强 VEH 会在异常末尾留下 EIP/RVA、寄存器、对象和最近 128 次脚本事件。
